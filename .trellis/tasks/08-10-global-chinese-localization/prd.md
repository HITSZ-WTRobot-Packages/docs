# 全站中文化与品牌统一迁移

## 目标

将文档门户及仓库自有文档统一迁移为简体中文，使站点根语言、内置控件、页面内容、交互反馈、质量状态和维护文档均以中文呈现，同时保持技术标识、路由和上游快照稳定。

## 需求

- 将站点根 locale 设置为 `zh-CN`，生成页面的 `<html lang>` 和内容语言均为简体中文。
- 统一使用战队中文名“哈尔滨工业大学（深圳）南工问天”、战队英文名“HITSZ WTRobot”和项目名“HITSZ-WTRobot-Packages”，保留名称的空格、大小写与连字符。
- 使用 Starlight 的简体中文翻译，并补齐 Pagefind、标题锚点等未覆盖的内置可见/无障碍文案。
- 翻译 `src/pages/` 和 `src/components/` 中所有仓库自有的用户可见文本，包括标题、描述、导航、面包屑、表头、空状态、按钮、工具提示、ARIA 标签和客户端状态反馈。
- 翻译站点展示的 API 状态、依赖类型、符号类型、全局命名空间标签、快照警告和 Doxygen 质量警告。
- 翻译由仓库生成的模块/包 README 缺失降级内容；已有上游 README 内容保持原语言。
- 将 `README.md`、`docs/automation.md`、`docs/deployment.md` 和 `issues.md` 翻译为中文，保持命令、路径、环境变量、代码块、URL、状态值和问题 ID 不变。
- 更新 `AGENTS.md` 和适用 Trellis 规范，声明仓库自有文档与用户界面默认使用简体中文，上游同步内容保持原语言。
- 更新所有依赖可见文案的测试，并为 `zh-CN` HTML 语言标记和中文核心流程增加覆盖。

## 验收标准

- [x] 根路径及深层门户页面的 `<html lang>` 为 `zh-CN`，且不新增语言路由前缀。
- [x] 首页、模块页、包页、API 页、搜索页、质量页、404 页及 Starlight 公共控件不再显示仓库自有英文句子。
- [x] 搜索加载/结果/失败状态、依赖图模式/状态、复制命令反馈及所有可访问名称均为中文。
- [x] 生成式 README 降级页、快照警告和 API 质量警告为中文；上游文档、代码符号和技术缩写保持原样。
- [x] `README.md`、`docs/automation.md`、`docs/deployment.md` 与 `issues.md` 的叙述、标题、表格标签和模板均为中文。
- [x] `sources/` 无任何变更，现有路由、查询参数、数据枚举和诊断码保持兼容。
- [x] 格式、lint、类型检查、单元/集成测试、生成器、构建、产物、链接、Playwright、响应式与 axe 检查通过。
- [x] 站点标题、元数据、首页和仓库自有文档统一使用约定的中英文战队名及英文项目名。

## 完成定义

- 变更符合前后端 Trellis 规范和 `AGENTS.md` 工程合同。
- 自动化测试覆盖语言标记及主要中文交互流程。
- 根路径与嵌套 `BASE_PATH` 构建均保持有效，静态发布产物满足现有发布合同。
- 桌面端和移动端截图经人工检查，无文本截断、重叠或无障碍回归。

## 技术方案

采用单一简体中文根 locale。Starlight 负责框架内置翻译和 HTML 语言元数据，项目 i18n 文件补齐其中文资源缺口；业务文案继续放在现有 Astro/TypeScript 所有者中直接翻译，不引入运行时多语言抽象。展示层保留稳定的数据枚举和 Pagefind filter 值，仅翻译标签。生成式降级内容及会在门户呈现的诊断消息在源头中文化，保证每次离线生成结果一致。

## 决策记录

**背景**：站点目前默认英文，文案横跨框架配置、模板、客户端脚本和生成数据；简单替换构建产物会在下一次生成时失效。

**决策**：以 `zh-CN` 作为根路径唯一语言，翻译仓库拥有的文案源头和文档，保留上游内容及技术契约。

**影响**：无需多语言路由或运行时词典；测试需要同步改为中文断言。未来若增加第二语言，应另建任务引入明确的 locale 路由和共享词典。

## 不在范围内

- 不翻译或修改 `sources/`、测试夹具中的模拟上游内容、第三方许可证和上游代码注释。
- 不翻译包名、模块名、API 名、README/Doxygen/cpkg 等技术术语、命令、路径、URL、环境变量、枚举值和诊断码。
- 不迁移 `.trellis/` 工作流、技能、历史任务或内部测试名称；仅更新与语言规范直接相关的现行约定。
- 不增加英文站点、语言切换器或 `/zh-CN/` 路由。
- 不改变同步、构建、发布或数据架构。
