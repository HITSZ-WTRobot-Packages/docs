The package catalog tracks reusable STM32 + HAL drivers maintained by the HITSZ Wentian Robotics
Team. Each synchronized release records its upstream revision, package manifest, manual, dependency
relationships, license, and C/C++ API status.

## Package guarantees

- Package pages are generated from committed, revision-pinned snapshots.
- Install names and dependencies come directly from validated `cpkg.toml` manifests.
- Manuals preserve upstream language and link to source files at the synchronized commit.
- API pages report Doxygen coverage explicitly, including empty or undocumented packages.
